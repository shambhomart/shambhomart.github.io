# ShambhoMART — Master Project Document

**Project:** ShambhoMART  
**Repository:** `shambhomart/shambhomart`  
**Purpose:** Portable source of truth for the ShambhoMART website, brand, marketing workflow, decisions, and roadmap.

---

## 1. Project Overview

ShambhoMART is an online product-discovery and affiliate-commerce brand focused on useful, trending and value-oriented products for Indian customers.

**Core idea:** Build a trustworthy, premium-looking shopping destination that can showcase products and route customers to the relevant purchase/order flow.

**Business model:** Affiliate/product-commerce model. Product prices and commissions can change, so social creatives should not depend on fixed prices.

---

## 2. Brand Identity

- Brand name: **ShambhoMART**
- Tagline: **Quality You Can Trust.**
- Preferred visual identity: premium, clean, minimal, Apple-style.
- Primary brand colors: **Blue + White + Yellow**.
- ShambhoMART logo should appear consistently on creatives, normally at the upper-right.
- Avoid clutter and excessive text.
- Prefer original product images whenever available.

---

## 3. Social Creative Standard

Default workflow per product:

1. Carousel
2. Reel
3. Stories
4. Caption + hashtags

Default carousel = **4 images**:

1. Premium Hero Poster / Hook
2. Features
3. How to Use
4. Close-up + Trust + CTA

Default social formats:
- Carousel: 1080×1080
- Reel/Story: 9:16

Creative language can be Marathi + English mixed, with Devanagari Marathi preferred where appropriate.

### Pricing rule
**Do not show fixed product prices in social-media creatives.** Affiliate prices can change frequently.

Preferred promotional language:
- Limited Time Deal
- Special Offer
- Trending Product
- Bestseller
- Premium Pick
- Grab Yours Today
- Shop Now – Link in Bio

---

## 4. Website Direction

The website is separate from ChatGPT and is maintained in this GitHub repository.

Current direction:
- Product showcase/catalog
- Product detail pages
- Cart/order flow
- Clean responsive design
- Mobile + laptop/browser experience
- Exploded-view/product visual presentation where applicable

### Account system decision
**Login/Signup should currently remain removed/disabled.**

Reason: avoid unnecessary friction and complexity while traffic is still being built. Revisit account creation after meaningful traffic/orders begin.

Future account features, if activated:
- Customer account
- Order history
- Cart persistence
- Profile management

## 5. Product Research Standard

Products should be evaluated using factors such as:
- Demand
- Rating
- Review volume
- Competition
- Affiliate commission
- Return risk
- Seasonality
- Product usefulness
- Visual/social-media potential

The project has previously focused on kitchen/useful household products and selected promising products for promotion.
